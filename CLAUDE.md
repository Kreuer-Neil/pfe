## Project Overview

**ComeUnite** — a community project coordination platform (PFE 2025-2026). Users can create, join, and collaborate on local community projects, with task management and member role systems.

Stack: **Laravel 12** (PHP backend) + **React 19** (TypeScript frontend) via **Inertia.js**, styled with **Tailwind CSS v4**. Auth via **Laravel Fortify**. Testing via **Pest**.

## Architecture

### Request Flow
1. Laravel routes (`routes/*.php`) → Controllers (`app/Http/Controllers/`)
2. `HandleInertiaRequests` middleware shares global props: `auth.user`, `sidebarOpen`, `name`, `quote`
3. `LoadUserNavData` middleware (on auth routes) eagerly loads `auth()->user()->projects` for the sidebar
4. Controllers return `Inertia::render('page/name', $data)` → React page at `resources/js/pages/`

### Frontend Structure (`resources/js/`)
- **`pages/`** — Inertia page components (one file = one route). Subdirs: `auth/`, `projects/`, `tasks/`, `settings/`, `profile/`
- **`layouts/`** — `app-layout.tsx` (wrapper) → `custom-app-layout.tsx` (sidebar toggle logic) → `custom-sidebar-cast.tsx` (renders sidebar). Auth pages use `auth-layout.tsx`
- **`components/ui/`** — Base UI primitives built on Radix UI primitives (custom, not generated by shadcn CLI despite `components.json` being present — do not run `npx shadcn` to regenerate)
- **`components/`** subdirs: `modals/`, `tasks/`, `projects/`, `users/`, `form/`, `buttons/`, `filtering/`, `dashboard/`, `general-posts/`, `icons/`
- **`actions/`** — Auto-generated typed route helpers from Laravel Wayfinder. Do not edit manually; run `php artisan wayfinder:generate` after route changes
- **`types/index.d.ts`** — All shared TypeScript interfaces (`IUser`, `IProject`, `ITask`, `IProjectMiniature`, etc.)
- **`hooks/`** — Custom hooks: `use-appearance`, `use-mobile`, `use-image-asset`, `use-initials`, `use-clipboard`, `use-mobile-navigation`
- **`utils/i18n.ts`** — i18next config; loads translations from `public/locales/{lang}/{ns}.json`

### Backend Structure (`app/`)
- **`Models/`** — `Project`, `Task`, `User`, `Member`, `Participation`, `ProjectInvitation`, `ProjectNews`, `Tag`, `ProjectTag`, `TaskNote`, `UserFollow`, `RepeatableTaskSetting`
- **`Http/Controllers/`** — `ProjectController`, `TaskController`, `UserProfileController`, `DashboardController`, `FrontpageController`, plus `Auth/` and `Settings/` subdirs
- **`Http/Resources/`** — API Resources for shaping Inertia props; subdirs `Project/` (e.g. `ProjectResource`, `ProjectMiniatureResource`, `ProjectDashboardResource`) and `User/`
- **`Policies/`** — `ProjectPolicy` and `TaskPolicy` (checked via `Gate::allows()` / `Gate::authorize()`)
- **`Enums/`** — `ProjectRole` (admin/moderator/task_manager/member/banned/viewer), `ProjectAction`, `ProjectsFilters`, `Language`, `ProjectInvitationResponse`
- **`Jobs/`** — `HandleProfileImageUploads`: queued job that creates small/medium/large PNG variants using Intervention Image

### Authorization Model
`ProjectRole` controls what actions a member can perform. Checked in `ProjectPolicy` and directly in controllers via `Gate`. The `Project` model has a `permission(User, ProjectAction)` method for internal checks. Key roles:
- `admin` — full control except delete
- `moderator` — can manage members and create tasks
- `task_manager` — can create tasks only
- `member` — basic interactions
- `viewer` — non-member viewing public projects

### Modals
Custom `<dialog>` element-based modal system in `components/modals/`. Use `CustomModal` + `ModalContent`, `ModalHeader`, `ModalFooter`, `ModalTitle`, `ModalDescription` sub-components. Not Radix Dialog.

### Internationalization
- Backend: PHP lang files in `lang/{en,fr,de}/` for Fortify/validation strings
- Frontend: JSON files in `public/locales/{en,fr,de}/{namespace}.json`, loaded via `i18next-http-backend`. Namespaces: `common`, `auth`, `dashboard`, `projects`, `projects-index`, `modals`, `errors`, `date`, `pagination`, `tags`, `profile`
- Active language stored in `document.documentElement.lang`, switchable via `GET /lang`

### Image Handling
Profile and project images are uploaded to `storage/app/public/images/{users|projects}/` then processed by the `HandleProfileImageUploads` queue job into three sizes (small=32px, medium=64px, large=160px) as PNGs. Requires the queue worker running (included in `composer run dev`).

### Enum Sync
When editing `ProjectRole` or other enums used on both sides, update the corresponding TypeScript types in `resources/js/types/index.d.ts` as noted by the comment in `ProjectRole.php`.



## Location feature (Nominatim + Haversine)

### Goal
Allow users to add a location to their projects and see distance from their own location.

### Stack decisions
- Geocoding: Nominatim (OpenStreetMap) — free, no API key needed
- Distance: Haversine formula server-side (no API needed for straight-line distance)
- Cache: Laravel Cache with `md5($query)` as key, TTL 1 day
- Rate limiting: debounce on frontend (1s after typing stops) + `throttle:60,1` on the Laravel route as safety net

### Database
**`locations` tables:**
- `latitude` / `longitude` (decimal, for Haversine + map display)
- `display_name` (string, full readable name from Nominatim)
- `name` (string, short name for compact display e.g. "Liège")
- `osm_id` (integer)
- `osm_type` (string: node/way/relation)
- `type` (string: city/suburb/road etc., useful for filtering by proximity type)

// Custom note: Will be a foreign key on projects and UserPreferences

### UX: dual input mode
Two modes, same stored output (`coordinates` + `display_name`):
1. **Free search** — autocomplete bar, user types "Outremeuse", picks from Nominatim suggestions
2. **Precise mode** — separate fields (street / number / city / postal code), query built server-side

### API call (frontend)
```tsx
const searchLocation = async (query: string) => {
    const response = await fetch(
        `https://nominatim.openstreetmap.org/search?q=${encodeURIComponent(query)}&format=json&limit=5`,
        { headers: { 'Accept-Language': 'fr', 'User-Agent': 'ComeUnite/1.0' } }
    );
    return response.json();
};
```

### Cache (backend)
```php
$results = Cache::remember('nominatim_' . md5($query), now()->addDay(), function() use ($query) {
    return Http::withHeaders(['User-Agent' => 'ComeUnite/1.0'])
        ->get('https://nominatim.openstreetmap.org/search', [
            'q' => $query, 'format' => 'json', 'limit' => 5,
        ])->json();
});
```
